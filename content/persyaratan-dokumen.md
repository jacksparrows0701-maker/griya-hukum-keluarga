## Persyaratan Dokumen per Layanan

Pilih layanan yang Anda butuhkan untuk melihat dokumen yang harus disiapkan:

### [Cerai Gugat](/cerai-gugat)

Untuk istri yang ingin mengajukan gugatan cerai:

- [ ] Fotokopi KTP suami dan istri
- [ ] Fotokopi KK (Kartu Keluarga)
- [ ] Surat nikah asli
- [ ] Akta kelahiran anak (jika ada)
- [ ] Bukti penghasilan (slip gaji, rekening koran)
- [ ] Bukti domiciliili
- [ ] Surat keterangan dari Kelurahan/Desa
- [ ] Foto-foto pendukung (jika ada bukti KDRT, dll)
- [ ] Surat gugatan dari pengacara

[Baca panduan lengkap →](/cerai-gugat)

### [Cerai Talak](/cerai-talak)

Untuk suami yang ingin mengajukan talak:

- [ ] Fotokopi KTP suami dan istri
- [ ] Fotokopi KK
- [ ] Surat nikah asli
- [ ] Akta kelahiran anak (jika ada)
- [ ] Bukti penghasilan
- [ ] Surat keterangan dari Kelurahan/Desa
- [ ] Surat permohonan talak dari pengacara

[Baca panduan lengkap →](/cerai-talak)

### [Pembagian Waris](/waris)

Untuk penetapan ahli waris:

- [ ] Surat keterangan meninggal dunia dari RS/dukun/dokter
- [ ] Surat keterangan kematian dari Kelurahan/Desa
- [ ] Surat nikah pewaris (jika menikah)
- [ ] KK pewaris terakhir
- [ ] Akta kelahiran semua ahli waris
- [ ] Fotokopi KTP semua ahli waris
- [ ] Daftar harta peninggalan pewaris
- [ ] Surat permohonan penetapan ahli waris dari pengacara

[Baca panduan lengkap →](/waris)

### [Isbat Nikah](/isbat-nikah)

Untuk pengesahan nikah yang belum tercatat:

- [ ] Fotokopi KTP suami dan istri
- [ ] Fotokopi KK
- [ ] Akta kelahiran suami dan istri
- [ ] Surat keterangan menikah dari tokoh agama/pejabat
- [ ] Saksi-saksi pernikahan (2 orang)
- [ ] Foto-foto pernikahan
- [ ] Surat permohonan isbat nikah dari pengacara

[Baca panduan lengkap →](/isbat-nikah)

### [Hak Asuh Anak](/hak-asuh-anak)

Untuk penetapan hak asuh anak:

- [ ] Akta kelahiran anak
- [ ] Fotokopi KTP kedua orang tua
- [ ] Fotokopi KK
- [ ] Surat nikah atau putusan perceraian
- [ ] Bukti penghasilan (slip gaji, rekening koran)
- [ ] Bukti kedekatan dengan anak (foto, keterangan tetangga)
- [ ] Surat keterangan dari sekolah anak
- [ ] Surat gugatan hak asuh anak dari pengacara

[Baca panduan lengkap →](/hak-asuh-anak)

### [Harta Gono-Gini](/harta-gono-gini)

Untuk pembagian harta bersama:

- [ ] Surat nikah
- [ ] Surat putusan cerai (jika sudah cerai)
- [ ] Daftar harta bersama (aset, kendaraan, tanah, dll)
- [ ] Bukti kepemilikan aset (sertifikat, BPKB, rekening bank)
- [ ] Bukti penghasilan kedua belah pihak
- [ ] Surat permohonan pembagian harta dari pengacara

[Baca panduan lengkap →](/harta-gono-gini)

## Tips Persiapan Dokumen

1. **Siapkan sejak awal** — Jangan menunggu hari sidang untuk menyiapkan dokumen
2. **Fotokopi berlebihan** — Siapkan minimal 2 set fotokopi untuk setiap dokumen
3. **Dokumen asli** — Bawa dokumen asli saat sidang untuk diverifikasi
4. **Konsultasi dulu** — Hubungi kami untuk memastikan dokumen yang Anda siapkan lengkap
